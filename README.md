# Student-Detail-CRUD
A simple Angular Student CRUD Application using Reactive Forms, Form Validation, and Local Storage with Create, Read, Update, Delete operations.

## Features

- Student Registration Form
- Required and Optional Fields
- Form Validation
- Create Operation
- Read Operation
- Update Operation
- Delete Operation
- Local Storage Integration
- Responsive UI Design

## Technologies Used

- Angular
- TypeScript
- HTML
- CSS
- Local Storage

  ## Validation Included

### Required Fields
- Name
- Email
- Age

### Optional Fields
- Department
- Phone

## CRUD Operations

- Add Student
- View Student List
- Edit Student Details
- Delete Student Details

## Local Storage

The application stores student data using browser local storage.
